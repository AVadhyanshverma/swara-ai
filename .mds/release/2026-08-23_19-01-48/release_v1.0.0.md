# Swara AI - Initial Release (v1.0.0) 🚀

Welcome to the very first official release of **Swara AI**—an advanced, autonomous agentic workflow framework! This initial release brings together all our hard work on LLM orchestration, secure memory, dynamic tool-use, and cross-platform capabilities into standalone executables.

## 🎉 What's Included

- **Standalone Cross-Platform Binaries:**
  - `SwaraAI-Windows.exe` - No Python required! Double-click to run on Windows.
  - `swara-ai-linux` - Native executable for Linux/Kali environments.
- **Dual Interface Modalities:**
  - **FastAPI Web UI:** A beautiful, responsive, dark-themed UI featuring markdown rendering, code block syntax highlighting, and interactive visual mindmaps. It opens seamlessly in your default browser.
  - **Terminal CLI Mode:** A fast, lightweight interactive terminal experience (accessible via the `--cli` argument).
- **Secure Encrypted Memory:**
  - Features local SQLCipher-encrypted SQLite chat history, keeping all interactions highly secure.
  - Implements a custom Vector DB for intelligent semantic search and context retention.
- **Dynamic Tool Execution:**
  - **PyX-Builder integration:** Secure sandbox execution for Python code generated by the agent.
  - **Browser Automation:** Deep integration with Playwright MCP for web navigation and data extraction tasks.
  - **Math Solver & Visualization Tools:** Solves complex equations dynamically and visualizes thought chains.
- **Polished Startup Experience:**
  - Clean CLI logs with a massive ASCII art banner.
  - Professional Server Status logging with exact localhost links and shutdown hints.

## 🛠️ How to run
1. Download the executable for your respective operating system below.
2. (Linux) Run `chmod +x swara-ai-linux` to make it executable.
3. Simply execute the binary! A terminal window will open with our awesome ASCII banner and boot the UI locally at `http://127.0.0.1:8080/`.
