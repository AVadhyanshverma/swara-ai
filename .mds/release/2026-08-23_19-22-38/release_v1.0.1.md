# Swara AI - Patch Release (v1.0.1) ✨

This release brings several quality-of-life improvements, vital UI updates for our hackathon submission, and improved packaging for Linux users!

## 📦 What's New

- **Linux AppImage / Executable Formatting:**
  - We've streamlined the Linux build to ensure it functions cleanly as a standalone executable (similar to `.AppImage` formatting). Linux users can simply make the file executable (`chmod +x`) and run it seamlessly without dependencies!
- **Enhanced Startup UI Logging:**
  - The Web UI now boots up with a beautiful, fully stylized ASCII banner and a professional Server Status block in the terminal. It provides clear localhost URLs and hints for shutting down safely.
- **Refined Documentation & Presentation:**
  - Massive overhaul to the `README.md` to properly include high-resolution, precisely cropped screenshots of the UI.
  - Rebuilt the repository architecture tree to perfectly reflect the final codebase structure.
  - Enforced strict Git ignores on development environments (like `.venv`) and internal `DEVPOST.md` drafts to keep the repo pristine for judges.

## 🛠️ How to run
1. Download the executable for your respective operating system below.
2. (Linux) Run `chmod +x swara-ai-linux` (or the equivalent file) in your terminal to grant execute permissions.
3. Simply run the binary! The local server will boot and Swara AI will open in your default browser.
