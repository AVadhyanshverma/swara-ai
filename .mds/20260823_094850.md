# Work Log: Fix Markmap Iframe Sizing Bug

## Summary of Changes
Fixed a critical race condition in `app.js` that caused mindmaps to render squished at the top of the preview window. 

## Code Changes & Enhancements

1. **Delayed `srcdoc` Assignment**:
   - `markmap-autoloader` dynamically scales and positions the SVG graph based on its container's dimensions.
   - Previously, the iframe `srcdoc` was populated *before* the iframe was attached to the live DOM. This resulted in an initial height of `0px`, forcing the mindmap to scale incorrectly.
   - Refactored `app.js` to assign `iframe.srcdoc` only *after* the `tabsContainer` is fully inserted into the DOM. The iframe now calculates its actual flex height before the mindmap script triggers, correctly vertically centering and filling the rounded white box.
