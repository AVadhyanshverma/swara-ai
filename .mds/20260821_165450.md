## Tasks Completed & Mistakes Addressed:
1. **Mistake 1 - The Router Parsing Bug:**
   - DeepSeek-V4 models output chain-of-thought inside `<think>` tags. The router was failing because `max_tokens=10` truncated the `<think>` block, meaning the router returned the word "think" instead of the actual classification (e.g., "research"). This caused all tasks to default to the "chat" model.
   - **Fix:** Increased `max_tokens=150`, wrote regex to strip out `<think>` blocks, and successfully mapped to the intended keyword.

2. **Mistake 2 - Incomplete System Prompt Engineering:**

   - **Fix:** We realized that a single prompt isn't enough for a multi-model swarm. Instead of one monolithic prompt, I implemented **Dynamic Role-Based Prompting**.

3. **Delegation & Light Context Workflows:**

Instead, they must use the `create_file` tool to save their heavy work into the workspace, and then return to the chat providing a **very light context** (1-2 sentences) pointing the user to the generated file.
