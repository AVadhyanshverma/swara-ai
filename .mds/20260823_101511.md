- Implemented the "Rename" thread feature:

  - Backend (`main.py`): Created a `PATCH /api/threads/{thread_id}` endpoint. It executes an `UPSERT` (`INSERT ... ON CONFLICT DO UPDATE`) query into `threads_metadata`.

- Changed frontend string rendering (`app.js`) to display **"Unnamed Chat"** for new threads lacking a title, instead of showing the raw UUID prefix.
- Confirmed that after a message finishes streaming, the frontend reloads the threads, displaying the auto-generated title created in the backend's background task.
